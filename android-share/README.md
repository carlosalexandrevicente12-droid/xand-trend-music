# XAND MUSIC — Android Share (protótipo)

Recebe links TikTok pelo menu Compartilhar e armazena uma fila local persistente, em ordem de chegada, sem duplicação exata. O usuário marca manualmente cada item concluído. Nenhuma publicação automática, acesso ao ChatGPT, busca Pinterest ou geração de arte está implementada nesta versão.

Build: GitHub Actions -> Android share APK -> artefato debug APK. A compilação ainda precisa ser validada. O APK debug não é indicado para distribuição pública.

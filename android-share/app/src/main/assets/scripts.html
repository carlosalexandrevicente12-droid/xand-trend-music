XAND SCRIPTS

Biblioteca local de procedimentos para automações por nós.

Comandos disponíveis

AVISAR Sua mensagem — mostra um aviso na tela.

COPIAR_LINK — copia o link do TikTok.

ABRIR_TIKTOK — abre o link no TikTok.

MANTER_NA_FILA — mantém o registro na fila, sem duplicar.

Linhas iniciadas com # são comentários. Scripts só executam quando vinculados a um nó de automação ativo. Não executam comandos de sistema, JavaScript nem código externo.
